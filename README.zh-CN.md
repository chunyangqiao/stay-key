# Stay Key

[English](README.md) | 简体中文

Stay Key 是一个本地优先的 Chrome 密码库，运行在浏览器侧边栏中。站点账号和密码只保存在本机：没有账号体系，没有云同步，也没有遥测。

扩展界面目前为简体中文。

## 功能

- **侧边栏**——点击工具栏图标，或按 `Ctrl+Shift+Y`（macOS 为 `Command+Shift+Y`），在页面旁打开保险库。
- **当前站点**——列出与当前标签页匹配的条目，包括父域和子域。本站还没有条目时，可以直接新建并预填当前站点。
- **搜索**——按站点、账号或标签查找条目。
- **条目**——新建、编辑、删除条目，字段包括站点、账号、密码和标签。
- **列表打码**——列表中的账号会部分打码，密码不会出现在列表里。
- **复制**——复制账号或密码。若剪贴板里仍是刚复制的内容，Stay Key 会在短暂延迟后清除它。可选 15、30 或 60 秒，默认 30 秒。
- **解锁**——6 位数字主密码，或设置时自己编写的提示问题与答案。通过答案找回后需要设置新的主密码。
- **失败冷却**——主密码或提示问题答案连续失败多次后，会暂停一段时间再试。
- **自动锁定**——空闲一段时间后自动锁定。可选 1 到 30 分钟，默认 2 分钟。系统锁屏会立即结束本次解锁。
- **主题**——浅色、深色或跟随系统。

首次启动时，Stay Key 会请你设置 6 位数字主密码和提示问题，然后在本机创建加密保险库。

## 安全

保险库只保存在这台电脑上，并且经过加密。6 位数字主密码很短，请把提示问题答案写成难以猜到的内容。Stay Key 不能防范本机上的恶意软件，也不能防范已经拿到解锁会话的人。清除剪贴板是尽力而为。项目尚未经过独立审计。卸载扩展会删除其中的数据，目前也没有导入或导出。

## 本地开发

环境要求：Node.js 22.12 或更新版本、pnpm 12.15.0、Google Chrome 114 或更新版本。

```bash
pnpm install
pnpm dev
```

打开 `chrome://extensions`，开启**开发者模式**，点击**加载已解压的扩展程序**，选择 `dist/`。点击工具栏图标打开 Stay Key，或按 `Ctrl+Shift+Y`（macOS 为 `Command+Shift+Y`）。

```bash
pnpm build
```

生产构建输出到 `dist/`，压缩包输出到 `release/`。

`pnpm lint` 检查 `src/`，`pnpm fmt` 格式化 `src/`。
